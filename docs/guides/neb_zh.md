# NEB 最小能量路径 {#guide_neb}

[English](neb.md)

NEB（弹性带方法）在已知初态与终态之间求迁移、反应或相变路径。它优化一串“图像”
（沿路径排列的结构副本），不是分子动力学轨迹。

不涉及：端点结构的求解（见[结构弛豫](relaxation_zh.md)）、变胞与路径对称性的
进阶设置（见[并行与路径对称性](../advanced/neb-parallel-symmetry_zh.md)）。
数值收敛不保证模型能准确预测真实材料的势垒。

## 前置输入

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `initial.vasp` | 初态结构 | 初态弛豫后用 `convstr` 导出的 POSCAR |
| `final.vasp` | 终态结构 | 终态弛豫后用 `convstr` 导出的 POSCAR |
| `model.mtp` | 已训练的普通 MTP 模型 | 训练输出或模型提供方 |
| `index.map` | 模型元素顺序 | 模型或其训练记录 |

两个端点必须有相同原子数、相同元素及**逐行一致的原子身份**。固定胞 NEB 还要求同一
晶胞、坐标框架和边界条件：在相同晶胞、模型与约束下分别弛豫两个端点，不要把两个独立
变胞后的不同晶胞直接用于固定胞 NEB。`initial.vasp` 与 `final.vasp` 需自己提供，
`neb` 不会生成这两个文件。

NEB 不会自动匹配等价原子。空位迁移中同一个原子可以在两端移动，但不能仅为了让
POSCAR 看起来整齐而重排其中一个端点的原子行。周期边界下还要确认位移分支对应研究的
迁移方向，最小镜像并不总是想研究的路径：

> 10 Å 长的正交周期盒中，同一原子沿 x 从 9.8 Å 移到 0.2 Å，直接坐标差是 −9.6 Å，
> 而跨边界的最短位移是 +0.4 Å。若研究的正是这次跨边界跳跃，应确认初始化路径沿 +x
> 穿过边界，且两个端点中该原子仍在同一行；不能通过重排原子行“修复”路径。
> 若要研究绕盒的长路径，则需显式准备相应展开或中间图像。

## 命令与配置

以下使用 7 张图像，**包含两个端点**，编号 0 到 6；中间缺失图像自动初始化。
保存为 `neb.ini`：

```text
index index.map
pot:potfile model.mtp
nimgs 7
image:0 initial.vasp
image:6 final.vasp
driver fire
maxiteration 500
gtol 0.02
max_move 0.05
num_threads 1
neb:solver_policy stable-v1
neb:init_method idpp
neb:spring 1
neb:climb true
```

```sh
imrmlp neb neb.ini > neb.log 2>&1
echo $?
tail -n 20 neb.log
```

`neb` 是 `calc_neb` 的别名。这里显式选择 `stable-v1` 数值策略，使用 FIRE 和固定
图像数。`gtol` 对完整的活动 NEB 残差收敛；固定胞原子力单位为 eV/Å。图像数量、容差、
弹簧和步长都是示例，需要按目标机制检查。NEB 不读取 `relax:` 配置，顶层 `gtol`
会覆盖 `neb:gtol`。

### 初始化与爬升图像

| 选择 | 作用 | 注意 |
| --- | --- | --- |
| `neb:init_method linear` | 在已提供图像之间插值 | 交换原子或复杂迁移时可能穿过重叠构型 |
| `neb:init_method idpp` | 通过插值的原子对距离改善初始路径 | 不能替代正确的原子匹配，也不保证找到目标机制 |
| `neb:climb true` | 对选中的高能图像使用爬升力，细化鞍点附近路径 | 仍需整条路径收敛及独立鞍点检查 |
| 最小镜像展开（默认启用） | 以最小镜像位移展开相邻输入图像 | 长距离或指定绕行路径应先明确自己的展开方式 |

程序写出初始化图像 `nebimage_0.vasp` 等；先看这些结构是否合理，再解释最终势垒。
已有更好的路径时，可按同一编号提供 `image:1` 等中间结构，避免依赖单纯端点插值。
只做普通 NEB 时，在独立运行中设置 `neb:climb false`，随后保留整条路径再精修。

## 输出与判据

| 输出 | 用途 |
| --- | --- |
| `neb.log` | 运行信息、报错和停止原因 |
| `neb.dat` | 路径数据、`# converged`、`# status`、`# max_neb_force` 等摘要 |
| `mep.xyz` | 最终结构序列，用于逐张检查路径 |
| `nebimage_N_final.vasp` | 各最终图像；`N` 为从 0 开始的整数 |
| `neb.dat.iterations.csv` | 迭代诊断，区分接受步与试探/预算问题 |

退出码 0 表示收敛，2 表示正常结束但未收敛，1 表示错误；缺少设置文件的既有状态为
128。达到最大迭代或求值预算时仍可能写出最终路径，图像文件存在不等于收敛。
收敛要检查完整 NEB 残差，不能仅凭小的垂直力或图像能量变化判断。

固定胞下，`neb.dat` 的 `enthalpy` 列就是模型总能量，`ent_diff` 相对初态归零。
前向势垒为路径最高能量减初态能量，反向势垒减终态能量；这是该模拟体系的总 eV，
不是默认的每原子 eV。平滑插值曲线用于展示，不能替代实际鞍点求值。

### 从路径能量读势垒

假设某条已收敛固定胞路径的相对能量如下，仅用于说明读法：

| 位置 | 相对初态能量（eV） |
| --- | --- |
| 初态 | 0.00 |
| 路径最高能量图像 | 0.46 |
| 终态 | −0.05 |

前向势垒为 `0.46 − 0.00 = 0.46 eV`，反向势垒为 `0.46 − (−0.05) = 0.51 eV`；
终态比初态低 `0.05 eV`。不要用最高图像与其相邻图像的能量差代替势垒，也不要再除以
原子数。增加图像数后应同时比较最高能量、完整 NEB 残差和路径机制是否稳定。

## 续算与可信度

先检查路径的物理机制、原子距离和端点收敛，再比较更多图像、更紧容差及不同初始路径。
应独立核验最高能量图像是否为一阶鞍点：排除平移后 Hessian 恰有一个负模，是必要检查
之一。

保留原模型、元素映射、`neb.dat` 和全部 `nebimage_N_final.vasp` 后，可在备份的运行
目录中增加预算并续算：

```sh
imrmlp neb neb.ini --next_step > neb-restart.log 2>&1
```

示例沿用默认的固定图像数，因此 `nimgs` 保持不变。续算会更新同名输出，先保留原结果。
它恢复路径/阶段信息，但重建优化器历史，不保证与不中断运行逐步一致。变胞续算还需要
`neb_reference_cell.data`。更换模型、开启新约束或添加扰动时，应建立一份明确的新计算，
不能当成原计算的无变化续算。

## 扩展：MPI、变胞与路径对称性

- **MPI/OpenMP：** 多张图像可分给多个 rank；`--num_threads` 是每个 rank 的线程数。
  rank×线程数应与分配的 CPU 核数匹配，BLAS 线程还需单独控制。
- **VCNEB：** 两端点晶胞不同或研究受压相变时使用变胞路径，问题涉及晶胞度量、应力
  及焓。压力单位 GPa，输出已含 pV，不要重复加入；固定胞 `gtol` 不能原样解释为变胞的
  统一力容差。
- **对称性：** 约束共同子群可能降低成本，也可能排除更低路径，可用扰动和释放检查比较。
  空间群编号相同并不等于原子标签对应的整条路径具有相同对称性。

Dimer 与 mode following 的选择见[驻点与路径专题](../advanced/saddle-workflows_zh.md)。

## 常见错误

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 路径出现原子穿越或重叠 | 两端原子行身份不一致 | 保证同一原子在两端的行号一致，不要为排版重排原子 |
| 得到的机制不是预期方向 | 使用了最小镜像分支而非目标展开 | 显式准备展开或中间图像，或用 `neb:init_method linear` 配合手工图像 |
| 有 `nebimage_*` 文件但未收敛 | 预算耗尽仍写出最终路径 | 检查 `# converged`、`# status` 与完整 NEB 残差 |
| 势垒数值偏大或偏小一个数量级 | 把总 eV 当每原子 eV，或除以了原子数 | 固定胞势垒是体系总能量差 |
| 变胞计算的收敛判据失效 | 沿用固定胞 `gtol` 的含义 | 变胞坐标为广义坐标，需另作容差检查 |
| 改模型或加约束后结果不可比 | 当成无变化续算 | 作为新计算重跑，保留原结果的备份 |
