# NEB：从两个端点到最小能量路径 {#guide_neb}

[English](neb.md)

NEB（弹性带方法）用于已知初态和终态之间的迁移、反应或相变路径。
它优化一串“图像”（沿路径排列的结构副本），不是分子动力学轨迹。
先按[弛豫指南](relaxation_zh.md)准备端点，再运行固定晶胞 NEB；变胞及路径对称性
放在基础流程跑通后使用。

**还没有端点和模型？** [连续计算练习第 4 步](../../examples/basic-calculations/README_zh.md)
附带一个 LJ 空位跳跃的两端初猜、端点弛豫设置和 NEB 设置，可直接逐条运行。
先完成该练习的环境与输入准备。本页正文用于自己的普通 MTP 和迁移问题。
希望先训练再算路径时，使用 [MTP 连续练习](../../examples/mtp-workflow/README_zh.md)。

## 1. 准备端点与原子对应关系

准备 `initial.vasp`、`final.vasp`、`model.mtp` 和 `index.map`，放进新的任务目录。
两个端点必须有相同原子数、相同元素及**逐行一致的原子身份**。
固定胞 NEB 还要求同一晶胞、坐标框架和边界条件。先在相同晶胞、模型与约束下
分别弛豫两个端点，不要把两个独立变胞后的不同晶胞直接用于固定胞 NEB。
把两次端点弛豫的最终输出分别用 `convstr` 导出为 POSCAR，再复制到 NEB 任务目录，
分别命名为 `initial.vasp`、`final.vasp`；它们不是 `neb` 自动生成的输入。

NEB 不会自动匹配等价原子。例如空位迁移中，同一个原子在初态和终态可以移动，
但不能仅为了让 POSCAR 看起来整齐而重排其中一个端点的原子行。
周期边界下还需确认选择的位移分支对应研究的迁移方向；最小镜像并不总是想研究的路径。

例如，10 Å 长的正交周期盒中，同一个原子沿 x 从 9.8 Å 移到 0.2 Å，直接坐标差
是 −9.6 Å，而跨边界的最短位移是 +0.4 Å。若研究的正是这次跨边界跳跃，
应检查初始化路径沿 +x 穿过边界，且两个端点中该原子仍在同一行；不能通过重排
原子行“修复”路径。如果研究的是绕盒的长路径，则需显式准备相应展开或中间图像。

## 2. 保存最小固定胞配置

以下使用 7 张图像，**包含两个端点**，编号为 0 到 6；中间缺失图像自动初始化。
保存为 `neb.ini`：

```text
index index.map
pot:potfile model.mtp
nimgs 7
image:0 initial.vasp
image:6 final.vasp
driver fire
maxiteration 500
gtol 0.02
max_move 0.05
num_threads 1
neb:solver_policy stable-v1
neb:init_method idpp
neb:spring 1
neb:climb true
```

```sh
imrmlp neb neb.ini > neb.log 2>&1
echo $?
tail -n 20 neb.log
```

`neb` 是 `calc_neb` 的别名。这里显式选择 `stable-v1` 数值策略，使用 FIRE 和固定
图像数作为起点。`gtol` 对完整的活动 NEB 残差收敛；固定胞原子力单位为 eV/Å。
图像数量、容差、弹簧和步长都是示例，需要按目标机制检查。
NEB 不读取 `relax:` 配置，顶层 `gtol` 会覆盖 `neb:gtol`。

## 3. 理解初始化与爬升图像

| 选择 | 做什么 | 需要注意 |
| --- | --- | --- |
| `neb:init_method linear` | 在已提供图像之间插值 | 交换原子或复杂迁移时可能穿过重叠构型 |
| `neb:init_method idpp` | 通过插值的原子对距离改善初始路径 | 不能替代正确的原子匹配，也不保证找到目标机制 |
| `neb:climb true` | 对选中的高能图像使用爬升力，细化鞍点附近路径 | 仍需整条路径收敛及独立鞍点检查 |
| 最小镜像展开（默认启用） | 以最小镜像位移展开相邻输入图像 | 长距离或指定绕行路径应先明确自己的展开方式 |

程序会写出初始化图像 `nebimage_0.vasp` 等。先看这些结构是否合理，再解释最终势垒。
已有更好的路径时，可按同一编号提供 `image:1` 等中间结构，避免依赖单纯端点插值。
若想先做普通 NEB，可在独立运行中设置 `neb:climb false`；随后保留整条路径再精修。

## 4. 读取结果并判断收敛

| 输出 | 用途 |
| --- | --- |
| `neb.log` | 运行信息、报错和停止原因 |
| `neb.dat` | 路径数据、`# converged`、`# status`、`# max_neb_force` 等摘要 |
| `mep.xyz` | 最终结构序列，用于逐张检查路径 |
| `nebimage_N_final.vasp` | 各最终图像；`N` 为从 0 开始的整数 |
| `neb.dat.iterations.csv` | 迭代诊断，区分接受步与试探/预算问题 |

退出码 0 表示收敛，2 表示正常结束但未收敛，1 表示错误；缺少设置文件的既有状态为 128。
达到最大迭代或求值预算时仍可能写出最终路径，不能只看图像文件是否存在。
收敛要检查完整 NEB 残差，不能仅凭小的垂直力或图像能量变化来判断。

固定胞下，`neb.dat` 的 `enthalpy` 列就是模型总能量，`ent_diff` 相对初态归零。
前向势垒为路径最高能量减初态能量，反向势垒减终态能量；这是该模拟体系的总 eV，
不是默认的每原子 eV。平滑插值曲线用于展示，不能替代实际鞍点求值。

### 小例子：从路径能量读出势垒

假设某条已收敛固定胞路径的相对能量如下，仅用于说明读法：

| 位置 | 相对初态能量（eV） |
| --- | --- |
| 初态 | 0.00 |
| 路径最高能量图像 | 0.46 |
| 终态 | −0.05 |

前向势垒为 `0.46 − 0.00 = 0.46 eV`，反向势垒为
`0.46 − (−0.05) = 0.51 eV`；终态比初态低 `0.05 eV`。
不要用最高图像与其相邻图像的能量差代替势垒，也不要再除以原子数。
增加图像数后应同时比较最高能量、完整 NEB 残差和路径机制是否稳定。

## 5. 提高结果可信度与续算

先检查路径的物理机制、原子距离和端点收敛，再比较更多图像、更紧容差及不同初始路径。
应独立核验最高能量图像是否为一阶鞍点；排除平移后 Hessian 恰有一个负模，是
必要检查之一。数值收敛不保证模型能准确预测真实材料的势垒。

保留原模型、元素映射、`neb.dat` 和全部 `nebimage_N_final.vasp` 后，可在备份的
运行目录中增加预算并续算：

```sh
imrmlp neb neb.ini --next_step > neb-restart.log 2>&1
```

示例沿用默认的固定图像数，因此 `nimgs` 保持不变。续算会更新同名输出；先保留原结果。
它恢复路径/阶段信息，但重建优化器历史，不保证与不中断运行逐步一致。
变胞续算还需要 `neb_reference_cell.data`。更换模型、开启新约束或添加扰动时，应建立
一份明确的新计算，不能将其当成原计算的无变化续算。

## 6. 按需扩展到 MPI、变胞或路径对称性

- **MPI/OpenMP：** 多张图像可分给多个 rank；`--num_threads` 是每个 rank 的线程数。
  rank×线程数应与分配的 CPU 核数匹配，BLAS 线程还需单独控制。见[并行与路径对称性](../advanced/neb-parallel-symmetry_zh.md)。
- **VCNEB：** 两端点晶胞不同或研究受压相变时，使用变胞路径；涉及晶胞度量、应力及焓。
  压力单位 GPa，输出已含 pV，不要重复加入。固定胞 `gtol` 不能原样解释为变胞的统一力容差。
- **对称性：** 约束共同子群可能降低成本，也可能排除更低路径；可用扰动和释放检查比较。
  空间群编号相同并不等于原子标签对应的整条路径具有相同对称性。

这些设置及 Dimer、mode following 的选择见[驻点与路径专题](../advanced/saddle-workflows_zh.md)。
完整选项见[命令参考](../reference/commands_zh.md)。
